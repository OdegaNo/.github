## 3. 핵심내용
어데가노\!는 사용자가 원하는 해외 여행 감성·테마·먹거리·경험을 입력하면, 
이를 국내 관광지 데이터와 결합해 가장 비슷한 국내 여행 코스를 자동으로 설계해주는 AI 기반 여행 플래너입니다.</br></br>“프랑스에서 바게트 먹으며 산책하고 싶어”라고 말하면, AI는 국내에서 프랑스 감성을 느낄 수 있는 장소(예: 쁘띠프랑스, 프렌치 베이커리, 주변 관광지)를 분석하여 일정을 자동 생성해 줍니다.</br>“일본에서 온천하고 싶어요”와 같은 테마를 입력하면, 국내 온천 관광지 데이터를 기반으로 사용자가 원하는 분위기에 가장 가까운 여행지를 추천하고, 맛집·숙소 까지 포함된 일정표를 제공합니다.

## 4. 제안 배경 및 목적 
### [ 제안 배경 ]
<img src="https://media.discordapp.net/attachments/1434842040939839549/1440492684140871871/image2.png?ex=691e5ada&is=691d095a&hm=ea3b874f2b455e05ee095428536b0b1f9ce6a9d75660c9716a4ff125cf24dc9c&=&format=webp&quality=lossless&width=2210&height=1696" width="450px" alt="제안 배경 이미지"></img><br/>
- 최근 해외 여행 중 치안 문제, 사기, 납치, 실종 사건 증가 등이 사회적 이슈가 되고 있음 
- 환율 상승, 항공권 가격 폭등으로 인해 해외 여행의 비용 부담이 커짐 
- 그러나 사람들은 여전히 다른 나라의 분위기·음식·문화를 경험하고 싶어함 
- 국내에도 해외 분위기를 재현한 관광지, 음식점, 테마파크가 많지만 → 사용자가 스스로 찾기 어렵고 → 정보도 흩어져 있어 접근성이 낮음

### [ 목적 ]
- “해외 여행 대신 국내에서 같은 감성을 누릴 수 있게 해주자” 
- 사용자 의도(예: 프랑스 감성, 일본 온천, 태국 야시장 등)를 AI가 자연어로 이해해, 국내에서 가장 유사한 경험을 제공하는 여행 루트를 즉시 생성 
- 또한 국내 관광지의 재발견을 통해 지역 경제 활성화에 기여 
- 위험하고 비싼 해외 여행 대신 안전하고 합리적인 대안 여행을 제공

## 5. 세부내용
### [ 활용 데이터 및 AI 모델 ] 
활용 데이터 
- 전국관광지정보표준데이터: 852개 관광지 (명칭, 주소, 위도/경도, 설명) 
- 국내 지역별 유적지 데이터: 6,817개 유적지 (고궁,성,문,고택,생가,민속마을,유적사적 등) 정보 
AI 모델 및 기술 
- LLM: OpenAI GPT-4o-mini (사용자 입력에서 핵심 키워드 자동 추출) 
- 백엔드: FastAPI (Python) 
- 데이터베이스: MongoDB (관광지 데이터 저장 및 검색)

### [ 서비스 동작 방식 ] 
<img width="80%" src="https://media.discordapp.net/attachments/1434842040939839549/1440492683813457960/image1.png?ex=691e5ada&is=691d095a&hm=dfd3573fcdfba7542a25c23ac711e233c510e10ad04c858edcef6aadc8705b45&=&format=webp&quality=lossless&width=2128&height=1696">

1단계: 사용자 입력
- "일본에서 온천 여행하고 싶어요" 입력

2단계: AI 키워드 추출 GPT가 텍스트 분석 → 핵심 키워드 추출 
- 예: ["온천", "힐링", "전통", "노천탕", "료칸"]

3단계: 국내 관광지 매칭
- 키워드 기반으로 MongoDB에서 유사한 국내 관광지 검색 AI가 30개 후보 중 상위 10개 선정
  
4단계: 추천 결과 생성
- 장소명, 주소, 추천 이유, 위도/경도 포함한 결과 반환

5단계: 음식점, 숙소 추가 탐색
- 결과로 생성된 장소 주변을 Ai 가 탐색하여 주변 음식점, 숙소 등을 찾아 반환

### [ 기술적 차별점 ] 
| 기능 | 설명 |
|------|------|
| 자연어 이해 | 단순 키워드 매칭이 아니라 사용자가 입력한 문장 전체의 의도와 맥락을 AI가 해석해 더 정확한 여행 테마와 요구사항을 파악합니다. |
| 시맨틱 매칭 | 의미적 유사도를 이용해 사용자의 감성·테마와 데이터베이스의 관광지·맛집·숙소를 정교하게 연결하여 관련도가 높은 후보를 추천합니다. |
| 지도 연동 | 위도/경도 기반으로 추천 장소를 지도에 실시간 표시하고 경로·거리 정보를 제공해 일정 구성과 시각적 검토가 가능합니다. |
| RAG 처리 | 외부·내부의 실제 명소 데이터(문서·DB·API)를 참조하여 사실 기반으로 후보를 생성하고, 컨텍스트를 결합해 신뢰도 높은 추천을 만듭니다. |

## 6. 기대효과 
### [ 사회적 기대효과 ]
- 국내 관광지 재조명 → 지역 경제 활성화 
- 여행 준비 스트레스 감소 → 누구나 쉽게 여행 
- 안전한 국내 여행 문화 확산 
- 청소년·학생·가족 단위의 여행 접근성 향상 

### [ 경제적 기대효과 ] 
- 국내 관광 소비 증가 
- 지역 상권 매출 상승 
- 여행 관련 산업(숙박/교통/음식점) 동반 성장 
- 자동 일정 생성 기술을 기반으로 B2B SaaS 확장 가능
